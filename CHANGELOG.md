# Changelog

## 1.0.0

- First public package of Research Swarm and Outlier Swarm as one plugin.
- Both skills keep their phases, the 5-angle cap, the five lenses, the report templates, and the verdicts.
- Subagents, a notes vault, mission context, video transcripts, and daily notes are optional. If a tool is missing, skip that step or run the angles one by one.
- Reports default to `./research-reports/`.
- Outlier Swarm ships `scripts/fetch_page.sh` as an optional page-fetch fallback that needs Chrome.
